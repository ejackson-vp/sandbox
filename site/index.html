Pay, wake, work,
gone.

No account, no API key, no leftovers. The payment is the identity.

  1. 01

    Knock

    Ask for a machine and a price. The API replies with an x402 challenge.

    POST /v1/sessions → 402
  2. 02

    Wake

    Pay. Get a capability token bound to the guest's key.

    201 → READY
  3. 03

    Work

    Run commands, move files. The workspace lives as long as the lease.

    exec · file.put · file.get
  4. 04

    Gone

    Destroy it, or let the deadline do it. Machine stopped, disk wiped.

    DELETE → 200

01

Hosted

sandbox pricing --api-url {api}
sandbox run --api-url {api} -- python3 app.py

No cluster, no signup. Alpha, so expect downtime.

02

Your own cluster

git clone https://github.com/ejackson-vp/sandbox
make up            # kind + cilium + images + deploy
make demo-session  # pay, create, exec, files, destroy

Needs Docker, kind, kubectl, the Cilium CLI, Node 24+ and Go 1.26+. Local clusters use runc, not microVMs.
