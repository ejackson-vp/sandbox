on your laptop

Two minutes to your own.

Same API, relay and guest as a real deployment.

01

Local cluster

make up            # kind + cilium + images + deploy
make demo-session  # pay, create, exec, upload, download
make down

Needs Docker, kind, kubectl, the Cilium CLI, Node 24+ and Go 1.26+. Local clusters use runc, not microVMs. API on http://localhost:8080; GET /healthz is the cheapest check.

02

No cluster

npm ci
make verify  # typecheck, structure lint, unit + property
make test    # adds integration against the guest binary

Most of the system is testable in under a minute. make security-test needs a cluster and runs the packet-level isolation suite.

!

Alpha reference deployment, not a hosted service. Mock or testnet payments, no hardware attestation, checkpoints plaintext on disk. What is missing, in order.

the small print

In large type, because it matters.

Every claim has a test or a doc behind it. The gaps are listed the same way.

Holds today

  • The lease ends on time: guest watchdog, controller deadline, Kubernetes
  • Commands and files stay sealed in transit; the API, controller and relay see ciphertext
  • One Kata microVM per session, on tainted, default-deny nodes
  • The guest dials out to the relay; egress only through an allowlisting proxy on 443
  • No inbound sandbox networking

Not yet

  • No hardware root of trust: the dev attestation key ships in the repo
  • Checkpoints are plaintext on disk, readable by the storage admin
  • Mock or testnet payments, no mainnet
  • No GPUs, no arbitrary OCI images, no memory snapshots
  • Not parity with a general-purpose sandbox platform

Read the guarantee matrix and threat model before repeating any of this as a security claim.
